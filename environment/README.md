# Studio reflection environment

`studio_small_09_1k.hdr` is **Studio Small 09**, photographed by **Sergej Majboroda**
and published by Poly Haven under **CC0**.

- Asset: https://polyhaven.com/a/studio_small_09
- Download: https://dl.polyhaven.org/file/ph-assets/HDRIs/hdr/1k/studio_small_09_1k.hdr
- License: https://polyhaven.com/license

The viewer uses this local HDR for K1's paint, metal and glass reflections. It is
prefiltered on the GPU when K1 first opens. Browsing the viewer requires no request
to Poly Haven or any other external server. The isometric image manifest records
its SHA-256 checksum. Geometry and material definitions are separate from the HDR.
